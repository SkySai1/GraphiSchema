## Проверка обычного запуска и существующих данных

- Приложение проверено обычным запуском, без тестового флага.
- Backend использует каталог конфигурации приложения; настройки имеют права `0o600`.
- SQLite `PRAGMA quick_check`: **ok**.
- Обновление корзины проверено на действующей базе: **2 проекта, 5 веток, 1143 версии**. Все прежние ID, ревизии, даты и связи снимков сохранены; `foreign_key_check` пуст. Последняя схема и геометрия загружены новой сборкой; реальные проекты для проверки удаления не использовались.
- На копии действующей базы проверена миграция **1047 версий, 2 проектов и 5 веток**. ID снимков, даты, родители, головы и основания веток сохранены; исходная база оставлена на месте. Добавлена независимая нумерация коммитов внутри каждого проекта.
- Загружены существующие 9 объектов и 5 связей; геометрия получена через `neato`.
- Автоматические и живые Ollama-тесты создавали собственные временные репозитории, без добавления тестовых узлов в пользовательскую схему.

## Что исправлено во время проверки

- Штрихи и промежутки границ фигур масштабируются относительно толщины; скруглённые окончания не закрывают зазоры при 10 pt. Вид стандартной обводки 1,5 pt сохранён. Применено ко всем внутренним линиям иконок на холсте и в SVG/PNG/PDF. Новые проверки сначала воспроизвели ошибку (136 падений), затем прошли; JSON/DOT не меняются от рендера.
- Добавлена корзина в менеджере схем: 10 дней (240 часов UTC), восстановление без изменения ID снимков/голов веток, окончательное удаление с подтверждением. Фоновая очистка проверена без GET-запроса к корзине и без перезапуска.
- Удаление очищает собственные ветки, снимки, соответствия ревизий, undo/redo, настройки и привязки файлов. Родительский проект, соседние и дочерние форки сохраняют содержимое и историю. Проверены FK/quick_check, перезапуск, точная граница срока и повтор после ошибки очистки.
- Два редактора удалённого проекта переключаются на разные временные холсты; отложенное автосохранение не возвращает проект в базу. В AppKit проверены переключение списка/корзины, срок удаления, восстановление, отмена и подтверждение окончательного удаления; сохранён снимок `project-trash.png`.
- Добавлен выбор старта: последний активный проект с веткой или временный пустой холст. При отсутствии последнего проекта открывается временный холст; его просмотр и закрытие не регистрируют проект.
- Первая правка создаёт один снимок с именем `Unnamed-<случайный ID>` и поддержкой undo/redo. Повторы регистрации идемпотентны, ошибка записи откатывается атомарно. Просмотр DOT, проверка, экспорт, Ollama-предложение, настройки и системная тема не создают снимков пустого холста.
- Последний проект определяется активным основным или вспомогательным окном. Фоновое сохранение другого проекта не меняет выбор следующего запуска.
- Команды системного меню следуют за проектом активного основного или вспомогательного окна. Создание неактивного редактора не подменяет меню; при переключении проекта прежнее дерево закрывается.
- Импорт одинаковых JSON создаёт независимые проекты; открытие знакомого ID продолжает его историю. Изменённый файл сохраняется в собственной ветке без перезаписи main. Шаблон сохраняет ID целевого проекта.
- Общая SQLite запрещает чужие головы веток и родителей коммитов. Названия веток и нумерация коммитов независимы для проектов; Git для схем не используется.
- Ответы API запрещено кешировать; клиент проверяет принадлежность ответа проекту и отклоняет запоздавшие ответы. Конкурентные переключения не могут перезаписать идентификаторы друг друга.
- Ответ генерации Ollama сохраняет ID открытого проекта и применяется в его ветке.
- Проверка совместимости backend учитывает фактический каталог данных: отдельная конфигурация не подключается к чужому репозиторию.
- Темы проектов разделены; системный режим получает уведомления macOS, ручная тема другого проекта сохраняется.
- Длительное нажатие отсчитывается от события нажатия. Удержание маркера линии открывает текст, перетаскивание редактирует маршрут; временные подсветки очищаются.
- Рамка выделения находит пересекающие её связи, даже когда оба конца линии находятся снаружи.
- Неприменённый DOT защищён при импорте, переключении проекта и выходе.
- Все части составных фигур заполняются одним проходом; внутренние линии рисуются после заливки. Кривые на фиксированных портах имеют непрерывную касательную.
- Проверки SVG сравнивают геометрию и содержимое, сохраняя корректность при изменении сериализации.

Маршрутизация меню проверяется настоящими контроллерами и уведомлениями AppKit о смене активного окна: CLI-процессу macOS не всегда предоставляет фокус. Реальный Ollama использован для генерации; edit/review покрыты контролируемыми ответами в автоматических тестах. Захват окон WindowServer в этом окружении недоступен: для вспомогательных окон сохранены AppKit-снимки, которые не воспроизводят некоторые системные слои кнопок; они не служат доказательством пиксельной отрисовки этих кнопок. Их тексты, размеры, состояния и действия проверены отдельно. Растровые проверки холста и SVG выполнены напрямую.
