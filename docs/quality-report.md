## Что исправлено во время проверки

- Команды системного меню следуют за проектом активного основного или вспомогательного окна. Создание неактивного редактора не подменяет меню; при переключении проекта прежнее дерево закрывается.
- Импорт одинаковых JSON создаёт независимые проекты; открытие знакомого ID продолжает его историю. Изменённый файл сохраняется в собственной ветке без перезаписи main. Шаблон сохраняет ID целевого проекта.
- Общая SQLite запрещает чужие головы веток и родителей коммитов. Названия веток и нумерация коммитов независимы для проектов; Git для схем не используется.
- Ответы API запрещено кешировать; клиент проверяет принадлежность ответа проекту и отклоняет запоздавшие ответы. Конкурентные переключения не могут перезаписать идентификаторы друг друга.
- Ответ генерации Ollama сохраняет ID открытого проекта и применяется в его ветке.
- Проверка совместимости backend учитывает фактический каталог данных: отдельная конфигурация не подключается к чужому репозиторию.
- Темы проектов разделены; системный режим получает уведомления macOS, ручная тема другого проекта сохраняется.
- Длительное нажатие отсчитывается от события нажатия. Удержание маркера линии открывает текст, перетаскивание редактирует маршрут; временные подсветки очищаются.
- Рамка выделения находит пересекающие её связи, даже когда оба конца линии находятся снаружи.
- Неприменённый DOT защищён при импорте, переключении проекта и выходе.
- Все части составных фигур заполняются одним проходом; внутренние линии рисуются после заливки. Кривые на фиксированных портах имеют непрерывную касательную.
- Проверки SVG сравнивают геометрию и содержимое, сохраняя корректность при изменении сериализации.
