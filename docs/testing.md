# Проверка GraphiSchema

Все тесты Python используют временный репозиторий. Нативные режимы `*-test` используют отдельные настройки и backend; пользовательские проекты не открываются. Для AppKit нужен графический сеанс macOS.

## Команды

```bash
uv sync --extra dev
uv run pytest -q
./scripts/test_native_ui.sh
./scripts/test_native_interaction.sh
./scripts/test_native_projects.sh
./scripts/test_arrows.sh
./scripts/build_macos.sh local
./dist/GraphiSchema.app/Contents/MacOS/GraphiSchema --startup-smoke-test
codesign --verify --deep --strict dist/GraphiSchema.app
```

`test_native_projects.sh` поднимает настоящий локальный backend во временном каталоге, создаёт проекты и ветки, открывает несколько AppKit-окон и проверяет согласованность их состояний. Проверки не требуют Ollama: интеграция проверяется на контролируемых HTTP-ответах в Python.

## Диагностические материалы

`test_arrows.sh` сохраняет SVG, CSV с координатами, JSON с максимальной ошибкой стыка, общую таблицу и растры нативного рендера в `dist/arrow-debug/current/`. При обнаружении некликабельного нарисованного контура interaction-тест сохраняет `dist/interaction-debug/failure.png`.

Измерения реальных промежутков между штрихами/точками сохраняются в `dist/quality/borders/measurements.json`; рядом находятся PNG и PDF с границей толщиной 10 pt. Проверка учитывает скруглённые концы: видимый зазор равен заданному промежутку минус толщина линии и должен оставаться положительным. Она не вычисляет результат через функцию построения шаблона обводки.

Чистые геометрические тесты проверяют числовые инварианты независимо от количества SVG-команд. Отдельные растровые проверки наблюдают фактический AppKit/SVG-результат: сравнение только двух одинаково ошибочных формул недостаточно.

## Границы проверки

Внешние серверы Ollama, неподдерживаемые конструкции произвольного DOT, notarization Apple и особенности аппаратного драйвера конкретного тачпада требуют отдельного окружения. Синтетические события проверяют обе оси и natural scrolling, но не заменяют проверку физического устройства.

Для воспроизводимого просмотра всех фигур в обеих темах выполните `uv run python scripts/diagnose_figures.py`. Результат — SVG, PNG и CSV в `dist/quality/figures/`. Заливка проверяется на 54 фигурах; activity и AWS являются линейными символами без замкнутого корпуса.

Снимки вспомогательных окон в нативном прогоне используют захват собственного окна через WindowServer, а при недоступности захвата — AppKit. Последний вариант не воспроизводит некоторые системные слои кнопок и не используется как доказательство их пиксельной отрисовки. Доступность действий, текст, размеры, привязки и состояние контролов проверяются отдельно.

## Необязательный живой прогон Ollama

Для уже установленной локальной модели: `uv run python scripts/test_ollama_live.py --model qwen3.5:4b`. Скрипт использует только локальный endpoint и временные проекты, проверяет предложение, применение, SVG, undo/redo и изоляцию другого проекта. Основной pytest-набор не запускает модели и не требует сервера Ollama.
