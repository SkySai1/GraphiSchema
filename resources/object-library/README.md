# Local object library

GraphiSchema bundles a curated set of infrastructure SVG icons for its native drag and drop palette. The source collections are stored locally, so the palette works offline.

## Included collections

- [Tabler Icons](https://github.com/tabler/tabler-icons), MIT license. Curated outline icons are in `tabler-icons/outline/`; see `tabler-icons/LICENSE`.
- [Lucide](https://github.com/lucide-icons/lucide), ISC license. Curated SVG icons are in `lucide/icons/`; see `lucide/LICENSE`.

The icon files remain unmodified. The palette uses them as visual cues for object templates; GraphiSchema's diagram model and rendering do not depend on these assets.
